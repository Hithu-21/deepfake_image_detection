# AI-Based Deepfake Image Detection System

## 1. Project Overview

The **AI-Based Deepfake Image Detection System** is a deep learning application that classifies facial images into two categories:

- **REAL** – Images classified as genuine photographs.
- **FAKE** – Images classified as AI-generated faces.

The system uses MobileNetV2 with transfer learning and fine-tuning to extract image features and perform binary classification.

Users can upload an image through a Streamlit web interface and receive a prediction along with a confidence score.

## 2. Objectives

- Develop an AI-based system to identify AI-generated facial images.
- Apply transfer learning using a pretrained MobileNetV2 model.
- Fine-tune the model to improve classification performance.
- Build an interactive web application for image upload and prediction.
- Evaluate the model using standard classification metrics.

## 4. Dataset

The project uses the **140K Real and Fake Faces dataset** from Kaggle.

The dataset contains:
- 70,000 real facial images.
- 70,000 AI-generated facial images.

The real images originate from the Flickr-Faces-HQ (FFHQ) dataset, while the fake images were generated using StyleGAN.

The dataset is divided into training, validation, and testing sets.

## 5. Model Architecture

The project uses MobileNetV2, a convolutional neural network pretrained on ImageNet.

Transfer learning is applied by using the pretrained network as a feature extractor and adding classification layers.

The classification head consists of:
- Global Average Pooling
- Dense layer with 128 neurons and ReLU activation
- Dropout layer
- Output Dense layer with sigmoid activation

The model is subsequently fine-tuned to adapt the pretrained feature extractor to the facial image dataset.

## 6. Project Workflow

1. Load the facial image dataset.
2. Preprocess images by resizing them to 160 × 160 pixels and normalizing pixel values.
3. Load the pretrained MobileNetV2 architecture.
4. Train the classification layers using transfer learning.
5. Fine-tune selected layers of the pretrained network.
6. Evaluate the model using the test dataset.
7. Save the trained model.
8. Launch the Streamlit application.
9. Upload an image and obtain a REAL or FAKE prediction.

## 7. Performance Results

The fine-tuned model achieved the following results on the held-out test dataset:

| Metric | Result |
|---|---:|
| Accuracy | 85.68% |
| Precision | 89.90% |
| Recall | 80.38% |
| F1-Score | 84.87% |

These results measure performance on the project's Kaggle test dataset.

## 8. Application Features

- Upload JPG, JPEG, and PNG images.
- Preview uploaded images.
- Classify images as REAL or FAKE.
- Display prediction confidence.
- Interactive Streamlit interface.
- Uses the saved fine-tuned model for predictions.

## 10. Installation and Execution

### Step 1: Clone the repository

```bash
git clone <your-repository-url>
cd deepfake-image-detection
```

### Step 2: Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the application

```bash
streamlit run app/main.py
```

The application will open in the browser, usually at:

```text
http://localhost:8501
```

**Note:** The trained model file `models/best_model_finetuned.keras` must be present to run the application. The dataset is required for retraining and evaluation, but not for ordinary predictions.

## 11. Limitations

- The model is primarily trained to distinguish StyleGAN-generated faces from real FFHQ photographs.
- It may not reliably detect images generated by other AI models.
- It is not specifically trained to detect face swaps, facial reenactment, or video deepfakes.
- Prediction confidence does not guarantee that an image is authentic.
- Performance on external images may differ from performance on the Kaggle test dataset.

## 12. Future Enhancements

- Train and evaluate using additional synthetic image datasets.
- Improve generalization across different AI image generators.
- Explore face manipulation and face-swap detection.
- Develop a more comprehensive deepfake detection system.

## 13. Conclusion

This project demonstrates the application of deep learning and transfer learning for detecting AI-generated facial images.

By using MobileNetV2 and fine-tuning it on the 140K Real and Fake Faces dataset, the system achieved 85.68% test accuracy.

The Streamlit application provides a simple interface for uploading images and viewing predictions, demonstrating how a trained deep learning model can be integrated into a practical application.
